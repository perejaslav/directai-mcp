# DirectAI Campaign Create

## Goal

Создать кампанию из описания товара/услуги или YAML-файла. Запись — только
через штатный цикл `plan_write` → подтверждение → `apply_write` → read-back.
Новая кампания всегда создаётся ОСТАНОВЛЕННОЙ и остаётся незапущенной.

## Порядок работы

0. Вход: текст-описание или YAML (`references/campaign-template.yaml`).
   Недостающее из брифа спросить ОДНИМ списком (см. шаг 1).
1. Собрать бриф (не придумывать, только значения пользователя): логин, сайт/URL,
   регионы, товар/услуги, цель Метрики, счётчик, бюджет. Без всех пунктов
   дальше не идти. Бюджет — только цифрой пользователя; в планах не менять.
2. Сформировать структуру: группы по смыслу, фразы, минус-фразы,
   2–3 объявления на группу, быстрые ссылки, уточнения, DisplayUrlPath.
   Длины текстов — по лимитам Директа (пакет «Знания»), проверить до prepare.
3. Для новых фраз — `phrases_forecast` (регионы из брифа): показать спрос/цены,
   фразы без спроса убрать.
4. Показать пользователю ВСЮ структуру таблицей → правки → явное «да».
   Без «да» — никаких `plan_write`.
5. Запись строго по порядку, каждый шаг отдельным планом с read-back:
   `campaigns_create` (ЕПК/UNIFIED_CAMPAIGN по умолчанию, затем сразу
   `campaigns_state` suspend — состояние остановлена) → `adgroups_create`
   (регионы обязательны) → `keywords_add` → `ads_create` (DisplayUrlPath
   обязателен) → `extensions_create` → `negatives_set`.
6. Итог: ID кампании/групп/объявлений и ссылки, пометка «кампания НЕ запущена».
   Запуск (`campaigns_state` resume) — только по отдельной команде пользователя.

## Правила (общие для обоих скиллов v1.11)

- Бюджеты кампаний не менять никогда.
- Любая запись — только через штатный цикл
  prepare (`plan_write`) → подтверждение пользователя → apply (`apply_write`)
  → read-back.
- Сравнение периодов — только `stats_compare`, не двумя вызовами с ручной арифметикой.
- Длины текстов — по лимитам Директа (пакет «Знания»), проверять до prepare.
- DisplayUrlPath (отображаемая ссылка) — всегда заполнять и проверять в read-back.
- Вывод пользователю: русский, простым языком, кратко.
- Тестовые кампании — только с именем `[TEST DirectAI] …`; пауза/архив тестовой
  кампании разрешены, запуск тестовой кампании — нет.
- Guard-блокировка — защита, а не ошибка: остановиться и сообщить пользователю.

## YAML-вход

Шаблон — `references/campaign-template.yaml` (все данные вымышлены).
Поля: login, url, regions, product, goal, counter, budget, groups[] (name,
phrases[], negatives[], ads[] (titles[], texts[], display_url_path), sitelinks[],
callouts[]). Бюджет из YAML — только значение пользователя.
